# 영어 공부 루틴 · 휴대폰 앱 버전

월–목에 공부한 것을 기록하고, 하루 5문장 작문·말하기(Grammar in Use Intermediate 142개 유닛)를 연습하고, 금–일에 그 주 공부한 것을 복습 체크하는 앱입니다.
휴대폰 홈 화면에 설치해서 쓰는 웹앱(PWA)이라 앱스토어 없이 설치할 수 있고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

주소: https://sihuny227-rgb.github.io/english-routine/

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `giu-data.js` | 유닛별 작문·말하기 연습 문장 (교재 예문이 아닌 자체 작성 문장) |
| `manifest.webmanifest` | 앱 이름, 아이콘, 전체 화면 설정 |
| `sw.js` | 오프라인 실행과 새 버전 안내 |
| `icons/` | 홈 화면 아이콘 |

## 휴대폰에 설치하기

- **아이폰:** Safari로 주소를 열고 공유 버튼 → **홈 화면에 추가**
- **안드로이드:** Chrome으로 주소를 열고 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

## 기록은 어디에 저장되나요?

공부 기록과 작문 답은 각자의 휴대폰(브라우저) 안에만 저장되고 GitHub에는 올라가지 않습니다.
휴대폰을 바꾸거나 다른 기기로 옮길 때는 앱의 **설정 → 백업 파일 저장 / 백업 불러오기**를 쓰세요.

## 알림

- **설정 → 캘린더 알림 파일 받기**로 받은 파일을 휴대폰 캘린더에 추가하면 앱을 닫아도 매주 알림이 옵니다 (월–목 기록, 금–일 복습).
- **설정 → 앱 알림 켜기**를 누르면 앱을 열어 둔 상태에서 정한 시간에 알림이 옵니다.

## 고친 뒤 다시 올리기

1. `sw.js` 맨 위의 `VERSION` 숫자를 하나 올립니다 (`english-routine-v1` → `english-routine-v2`).
2. 바뀐 파일을 GitHub에 다시 올립니다.
3. 설치된 앱을 다시 열면 "새 버전이 준비됐어요" 안내가 뜨고, **지금 적용**을 누르면 바뀝니다.
